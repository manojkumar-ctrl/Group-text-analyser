# Group-text-analyser

🚀 Features

Text Analysis
Word & character count
Most frequent words
Stopwords removal
Readability score
Visualization

📊 Matplotlib for bar graphs, line plots, and comparisons
🔥 Seaborn Heatmaps for group-wise word frequency and sentiment correlation
☁️ Word cloud generation

Emoji Analysis
Extract and count emojis in text
Emoji frequency distribution
Sentiment/usage trends of emojis across groups
Group-Wise Comparison
Compare word usage across multiple groups

# How to Use?
1. Go to Whatsapp Group or personal chat
2. Export the Chat without Media
3. Click on the SideBar on our Text-Analyser to get UI to upload File.
4. Upload the File.
5. Get the text analysation.
